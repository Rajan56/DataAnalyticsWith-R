# Data analytics with R: did the heat recovery retrofit pay off?

A complete analysis in R of an energy efficiency investment at a fictional Nordic packaging plant.

**Live report:** https://rajan56.github.io/DataAnalyticsWith-R/

## The question

One of two board lines received a heat recovery unit. Energy per tonne fell afterwards and the full drop was reported as the saving. How much did the retrofit truly cause, what drives energy intensity, and did quality suffer?

## Methods

| Step | Method in R |
|---|---|
| Naive comparison | Welch two-sample t test (t.test) |
| Causal estimate | Difference in differences with a control line (lm with interaction) |
| Inference | HC3 heteroskedasticity robust standard errors, written from first principles |
| Drivers | Multiple linear regression with process covariates |
| Diagnostics | Parallel trends test, variance inflation factors, Shapiro-Wilk, Breusch-Pagan |
| Quality | Chi-squared test and logistic regression with odds ratios (glm) |
| Validation | Ten-fold cross-validated AUC and ROC curve |
| Business case | Saving, confidence range, CO2 and payback |

## Result

The naive before and after test reports a saving of 53.2 kWh per tonne. The difference in differences estimate is 37.7 kWh per tonne (95 % CI 30.2 to 45.2), worth about EUR 162 000 a year, with a payback of 2.6 years and not 1.8.

## Files

    analysis.R    simulates the data, runs every test and model, draws the figures
    report.R      builds index.html from the R results
    index.html    the published report, generated by R

## Reproduce

Put analysis.R and report.R in one folder, open R there and run:

    source("analysis.R")

Base R is enough. The svglite package is used for figures when installed. The run also writes data/plant_energy.csv, output/results.txt and figures/.

## About the data

The company is fictional and the data are simulated with a fixed seed. A true effect of -38 kWh per tonne is built in, so the analysis can be checked against a known answer.
